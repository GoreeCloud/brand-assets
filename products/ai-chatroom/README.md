## Original design and rights

Two distinct overlapping rounded conversation shapes carry three glowing model-color dots, arranged on a midnight navy glass-like tile. The forms are authored for this product from scratch, with palette roles referenced to the current GoreeCloud UI light/dark and Iris, Lagoon and Moss alpha tokens. No brand-new cross-product color specification is created here. The icon does not use the umbrella GoreeCloud G, the GoreeCloud UI Aperture Weave mark, OpenRouter branding or third-party marks.

Every SVG contains a title and accessible description, renders without network dependencies, JavaScript, animation or external font files. Future founder review of legibility, branding, real light/dark and actual device contexts remains necessary.
